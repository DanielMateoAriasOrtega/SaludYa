# SaludYa

Sistema web para la gestión de pacientes y citas médicas desarrollado como proyecto académico utilizando tecnologías Full Stack.

## Tecnologías Utilizadas

### Frontend
- React
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Base de Datos
- MySQL

### Pruebas
- Jest
- Supertest

### DevOps
- Git
- GitHub
- GitHub Actions

---

## Instalación

### Clonar repositorio

```bash
git clone https://github.com/DanielMateoAriasOrtega/SaludYa.git
```

### Entrar al proyecto

```bash
cd SaludYa
```

---

## Instalación Backend

```bash
cd server
npm install
```

### Ejecutar Backend

```bash
npm start
```

o

```bash
node index.js
```

Servidor disponible en:

```text
http://localhost:3001
```

---

## Instalación Frontend

```bash
cd client
npm install
```

### Ejecutar Frontend

```bash
npm start
```

Aplicación disponible en:

```text
http://localhost:3000
```

---

## Ejecución de Pruebas

```bash
npm test
```

### Cobertura

```bash
npx jest --coverage
```

Resultado obtenido:

```text
Cobertura: 86.44%
Pruebas exitosas: 16/16
```

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- CRUD de pacientes
- Gestión de citas médicas
- Agenda médica
- Historial clínico
- Dashboard
- Roles de usuario

---

## Arquitectura

El sistema utiliza una arquitectura cliente-servidor:

- Frontend desarrollado en React.
- Backend desarrollado en Node.js y Express.
- Persistencia de datos mediante MySQL.
- Comunicación mediante API REST.
